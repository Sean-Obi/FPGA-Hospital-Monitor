# KiCad files

Open `hospital_monitor_shield.kicad_pro` in KiCad 7 or later.

| File | What |
|---|---|
| `hospital_monitor_shield.kicad_sch` | the schematic |
| `hospital_monitor_shield.kicad_pcb` | the board, routed, with a ground pour on the back |
| `ECG.pretty/CmodA7_DIP48.kicad_mod` | footprint for the Cmod A7 socket (two 1x24 female headers, 0.6 in apart) |
| `fp-lib-table` | tells KiCad where that footprint library is |

Both files are generated by the scripts in `../tools/` from a single
description, so the schematic and board cannot drift apart:

```
python hardware/tools/make_schematic.py
kicad-cli sch export netlist --format kicadsexpr -o build/shield.net hardware/kicad/hospital_monitor_shield.kicad_sch
python hardware/tools/make_pcb.py build/shield.net          # placement, rules, outline -> .kicad_pcb + .dsn
java -jar freerouting.jar -de build/shield.dsn -do build/shield.ses -mp 50
python hardware/tools/finish_pcb.py build/shield.ses        # tracks in, ground pour, DRC-ready
python hardware/tools/render_pcb.py                         # the green renders in ../images
```

The library symbols and footprints are copied into the files, so they
open without any extra libraries installed.
